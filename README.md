# Frameworks for Policy, Law, Economics & Society

A static, networked knowledge repository modeled on [frameworks.pranaykotas.com](https://frameworks.pranaykotas.com/). It features dual Obsidian-style **Wikilink (List) View** and **Interactive Force Graph View**, automated typed relationships, backlinks, and instant client-side search.

---

## 🚀 Key Features

1. **Dual Views (One Data Source)**
   - **List View:** Clean typography, Obsidian-style `[[wikilink]]` syntax, automatically computed **Backlinks ("Linked from")**, and **Typed Relations** categorized by semantic relationship (`contrasts with`, `solution for`, `prerequisite for`, etc.).
   - **Graph View:** Force-directed dynamic topological map (powered by D3.js). Centered on active items, 1–2 hop neighbor expansion, zoom/pan, click-to-inspect, and double-click to navigate.
   - **URL State & Persistence:** State synchronizes via `?view=graph&node=...` and persists across sessions in `localStorage`.
2. **Find a Framework Instant Search**
   - Live client-side search filtering across titles, summaries, and categories.
   - Concurrently dims and highlights matching nodes and neighbors in the graph view.
3. **Automated Graph & Wikilink Extraction**
   - `scripts/build_graph.py` parses `.qmd` frontmatter and `[[item-id]]` links, computes the graph topology, and generates `assets/graph.json` and `assets/backlinks.json`.
4. **100% Free Hosting**
   - Ready-to-deploy `.github/workflows/deploy.yml` compiles and deploys to **GitHub Pages** (or Cloudflare Pages) completely for free with zero server costs and custom domain support.
5. **Newsletter Excerpt Pipeline**
   - `scripts/import_substack.py` extracts posts from a Substack export archive and maps matching excerpts to relevant policy frameworks.

## 💻 Local Quickstart

### 1. Preview the Site Locally
You can preview the site immediately with zero external dependencies:
```bash
python scripts/serve.py
```
Open **[http://localhost:8000](http://localhost:8000)** in your browser.

### 2. Add a New Framework
Create a `.qmd` file under `law/`, `policy/`, `economics/`, or `society/` (e.g. `economics/opportunity-cost.qmd`):

```markdown
---
id: opportunity-cost
title: "Opportunity Cost"
categories: ["Economics"]
summary: "The loss of potential gain from other alternatives when one alternative is chosen."
related:
  - id: coase-theorem
    type: "prerequisite for"
---

## Overview
Every resource allocation decision incurs an opportunity cost... You can link to other concepts using [[coase-theorem]] or [[pigouvian-tax]].
```

Then rebuild the graph:
```bash
python scripts/build_graph.py
```

### 3. Import Your Substack Newsletter
Place your unzipped Substack export folder in the project root and run:
```bash
python scripts/import_substack.py <path_to_substack_folder>
```

## 🌐 Free Hosting Guide (Zero Cost)

### Option A: GitHub Pages (Recommended)
1. Push this folder to a GitHub repository (public or private):
   ```bash
   git init
   git add .
   git commit -m "Initial commit of knowledge framework site"
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. Go to your repository on GitHub:
   - Navigate to **Settings** > **Pages**.
   - Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. The included workflow (`.github/workflows/deploy.yml`) will automatically trigger, build the graph, compile the site, and publish it at `https://<your-username>.github.io/<repo-name>/`. You can also attach any custom domain for free.

### Option B: Cloudflare Pages
1. Connect your GitHub repository to Cloudflare Pages.
2. Set Build Command: `python scripts/build_graph.py && quarto render` (or `python -c "import sys; sys.path.append('scripts'); import serve; serve.build_site()"`)
3. Set Output Directory: `_site`
4. Deploys with free global CDN and unlimited bandwidth.
