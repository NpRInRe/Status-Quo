# Status Quo — Personal Knowledge Blog & Idea Graph

**Author:** Neeraj Paulose Raj (NPR)  
**Subtitle:** Society’s existing states of affairs in law, policy, politics, and culture.  
**Substack:** [statusquotoday.substack.com](https://statusquotoday.substack.com)

A personal blog and digital garden that connects long-form essays with underlying conceptual models. Every piece is part of an evolving, searchable relational graph with dual **List View** and **Interactive Idea Graph View**.

---

## 🧭 Architecture: Law & Society

All essays, case studies, and conceptual analyses are organized into two primary pillars:

1. **⚖️ Law**: Constitutional jurisprudence, digital rights, data sovereignty, biometric surveillance regimes, courts, and statutory orders.
2. **🌐 Society**: The broader social order—encompassing public policy, economic mechanisms, market friction, collective action dilemmas, metrics gaming, and culture.

---

## 🚀 Key Features

1. **Dual Views, One Underlying Graph**
   - **List View:** Clean long-form reading typography with Obsidian/Wikipedia-style `[[wikilinks]]`, autogenerated **Referenced In (Backlinks)**, and **Connected Concepts**.
   - **Graph View:** A dynamic D3.js force-directed map showing how essays connect to underlying ideas and models. Centered on active items, with 1–2 hop neighborhood exploration, click-to-inspect, and double-click to navigate.
   - **URL State & Session Memory:** View state is shareable via `?view=graph&node=...` and saved in `localStorage`.
2. **Live Search**
   - Instant search bar on the home page filtering both essay cards and dynamically highlighting nodes in the knowledge graph.
3. **Local Context Graph on Every Post**
   - Each essay features its own local 1–2 hop interactive graph box so readers can see immediately what ideas intersect with the piece.
4. **Substack Newsletter Integration**
   - Real-world dispatches from `statusquotoday.substack.com` load asynchronously below the essay listings, mapping dispatches directly to relevant ideas.

## 💻 Local Quickstart

### 1. Preview the Blog Locally
```bash
python scripts/serve.py
```
Open **[http://localhost:8000](http://localhost:8000)** in your browser.

### 2. Publishing a New Essay
Create a `.qmd` file under `law/` or `society/` (e.g. `law/new-essay.qmd`):

```markdown
---
id: new-essay
title: "Title of Your Essay"
categories: ["Law"]
date: "2026-10-19"
author: "Neeraj Paulose Raj"
summary: "A one-line thesis of the piece."
start_here: true
related:
  - id: privacy-paradox
    type: "explores"
  - id: regulatory-capture
    type: "critique of"
---

Your essay text goes here... You can link to concepts using [[privacy-paradox]] or [[goodharts-law]].
```

Then rebuild the graph:
```bash
python scripts/build_graph.py
```
Backlinks and local graph visualizers will be injected automatically!
